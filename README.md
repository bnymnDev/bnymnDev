### Projects I'm proud of

| Project | What it does | Stack |
|---|---|---|
| [**agentgate**](https://github.com/bnymnDev/agentgate) | Policy, audit log and kill switch for MCP tool calls. A single-binary proxy between your agent and its tools — deny `rm -rf`, ask before destructive calls, freeze every agent on the machine, replay yesterday's session against tomorrow's policy. | Go, SQLite, MCP |
| [**spring-durable-agents**](https://github.com/bnymnDev/spring-durable-agents) | Durable execution for Spring AI agents. Crash, redeploy, resume. Spring Boot starter with PostgreSQL step store, human-in-the-loop approvals and Actuator endpoints. | Java, Spring Boot, PostgreSQL |
| [**shopware-mcp**](https://github.com/bnymnDev/shopware-mcp) | The MCP server for Shopware 6. Sixteen curated tools, a one-call shop health audit, sales reports, guarded dry-run writes — "Is everything okay with the shop?" answered in one prompt. | TypeScript, MCP |
| [**roofsight**](https://github.com/bnymnDev/roofsight) | Ground-level roof segmentation for PV installers: how many modules fit on that roof, from a phone photo instead of an aerial image. | Python, ML |
| [**uuidulid**](https://github.com/bnymnDev/uuidulid) | ULID and UUIDv7 for Java, plus the glue to use them as REST identifiers (Jackson, Spring, JPA). Zero dependencies, Java 8+. | Java |
| [**voltaris-demos**](https://github.com/bnymnDev/voltaris-demos) | Demo recordings of Voltaris, a native iOS app for photovoltaic planning built for electrical contractors. | Swift, CoreML |
